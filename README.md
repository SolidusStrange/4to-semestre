# 4to Semestre

Repositorio con mis apuntes, material de estudio y ejercicios correspondientes al **4to semestre**.

Las notas están organizadas principalmente utilizando **Obsidian**, incluyendo su configuración y los plugins utilizados para facilitar la organización y el estudio.

## Asignaturas

### [Desarrollo de Aplicaciones Móviles](https://github.com/SolidusStrange/4to-semestre/tree/main/Aplicaciones-Moviles)

Asignatura enfocada en el desarrollo de aplicaciones móviles.

Actualmente se trabaja con:

* **Java** — Introducción a la programación orientada al desarrollo móvil.
* **Kotlin** — Desarrollo principal de las aplicaciones.

### [Base de Datos](https://github.com/SolidusStrange/4to-semestre/tree/main/Base-de-datos)

Asignatura enfocada en el manejo y desarrollo de bases de datos utilizando **Oracle SQL**.

Contenidos actuales:

* Oracle SQL.
* Consultas y manejo de datos.
* Funciones SQL.
* **PL/SQL**.
* Bloques anónimos.
* Estructuras de programación en bases de datos.

### [Estadística Descriptiva](https://github.com/SolidusStrange/4to-semestre/tree/main/Estadistica)

Asignatura orientada al análisis y descripción de datos.

Actualmente se utiliza:

* **Python**
* **Pandas**

Incluye conceptos de estadística descriptiva y ejercicios de análisis de datos utilizando Python.

### [Fullstack 2](https://github.com/SolidusStrange/4to-semestre/tree/main/Fullstack-2)

Asignatura enfocada en el desarrollo web.

Tecnologías utilizadas actualmente:

* **HTML**
* **CSS**
* **JavaScript**

### [Ciberseguridad](https://github.com/SolidusStrange/4to-semestre/tree/main/Ciberseguridad)

Asignatura introductoria al área de ciberseguridad.

Contenidos actuales:

* Fundamentos de ciberseguridad.
* Conceptos y principios básicos.
* Introducción al **Blue Team**.
* Ciberseguridad defensiva.
* Protección y defensa de sistemas.

### [Obsidian](https://github.com/SolidusStrange/4to-semestre/tree/main/.obsidian)

Configuración utilizada para la organización de los apuntes mediante **Obsidian**.

Incluye la configuración y los plugins utilizados en la bóveda de apuntes.
